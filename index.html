Privacy Policy

Trasparenza e riservatezza
Ultimo aggiornamento: 31 luglio 2026

Introduzione

Railway Live è sviluppata da Claudio Manunta. Questa Privacy Policy descrive come raccogliamo e utilizziamo le informazioni quando usi la nostra app per la consultazione degli orari ferroviari italiani.

Dati raccolti

Dati raccolti automaticamente

  • Device token APNs — se attivi le notifiche push, raccogliamo il token univoco del tuo dispositivo per inviarti notifiche sui treni monitorati. Il token viene utilizzato esclusivamente per l'invio delle notifiche.

Dati che fornisci tu

  • Preferenze di ricerca — le stazioni preferite e le ricerche recenti vengono salvate localmente sul tuo dispositivo e non trasmesse ai nostri server.
  • Treni monitorati — i numeri dei treni che scegli di monitorare vengono salvati sul nostro server per permetterci di inviarti notifiche push.

Dati NON raccolti

Railway Live non raccoglie dati personali, non traccia la tua posizione, non utilizza analytics e non condivide nessun dato con terze parti a scopo commerciale.

  • Non raccogliamo nome, email o posizione GPS
  • Non raccogliamo dati di utilizzo o analitici
  • Non condividiamo dati con terze parti
  • Non utilizziamo cookie o tecnologie di tracciamento

Servizi di terze parti

L'app utilizza le API di ViaggiaTreno (Trenitalia) per recuperare i dati in tempo reale sui treni italiani. Non abbiamo controllo sui dati gestiti da Trenitalia.

Le notifiche push vengono inviate tramite il servizio APNs di Apple Inc.

Conservazione dei dati

Il device token viene conservato sui nostri server finché non disattivi le notifiche o disinstalli l'app. I treni monitorati vengono rimossi automaticamente alla mezzanotte del giorno di riferimento per i monitoraggi "solo oggi".

Sicurezza

Tutti i dati vengono trasmessi tramite connessioni HTTPS cifrate. Il device token viene conservato in modo sicuro e utilizzato esclusivamente per l'invio delle notifiche.

I tuoi diritti

Puoi in qualsiasi momento:

  • Disattivare le notifiche push dalle Impostazioni del tuo iPhone
  • Cancellare tutti i dati locali disinstallando l'app
  • Richiedere la cancellazione dei tuoi dati dal server contattandoci
