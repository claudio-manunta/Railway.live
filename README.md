# Privacy Policy — Railway Live

**Ultimo aggiornamento: 31 luglio 2026**

## Introduzione

Railway Live ("l'app") è sviluppata da Claudio Manunta. Questa Privacy Policy descrive come raccogliamo e utilizziamo le informazioni quando usi la nostra app.

## Dati raccolti

### Dati raccolti automaticamente
- **Device token APNs** — se attivi le notifiche push, raccogliamo il token univoco del tuo dispositivo per inviarti notifiche sui treni monitorati. Il token viene trasmesso al nostro server e utilizzato esclusivamente per l'invio delle notifiche.

### Dati che fornisci tu
- **Preferenze di ricerca** — le stazioni preferite e le ricerche recenti vengono salvate localmente sul tuo dispositivo e non vengono trasmesse ai nostri server.
- **Treni monitorati** — i numeri dei treni che scegli di monitorare vengono salvati sul nostro server per permetterci di inviarti notifiche push.

## Dati NON raccolti
- Non raccogliamo dati personali come nome, email o posizione GPS
- Non raccogliamo dati di utilizzo o analitici
- Non condividiamo nessun dato con terze parti
- Non utilizziamo cookie o tecnologie di tracciamento

## Servizi di terze parti
L'app utilizza le API non ufficiali di ViaggiaTreno (Trenitalia) per recuperare i dati in tempo reale sui treni italiani. Non abbiamo controllo sui dati gestiti da Trenitalia.

Le notifiche push vengono inviate tramite il servizio APNs di Apple.

## Conservazione dei dati
Il device token viene conservato sui nostri server finché non disattivi le notifiche o disinstalli l'app. I treni monitorati vengono rimossi automaticamente alla mezzanotte del giorno di riferimento (per i monitoraggi "solo oggi").

## Sicurezza
I dati vengono trasmessi tramite connessioni HTTPS cifrate. Il device token viene conservato in modo sicuro e utilizzato esclusivamente per l'invio delle notifiche.

## Diritti dell'utente
Puoi in qualsiasi momento:
- Disattivare le notifiche push dalle impostazioni del tuo iPhone
- Cancellare i dati locali disinstallando l'app
